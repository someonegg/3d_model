# 星链伸缩杖 · FDM

六节链条收拢成杆，逐节直拉展开后，可在一个平面内弯曲；卡位用于保持收拢形态，圆钝四角星形头可独立转动。用于手持变形和展示，不用于甩动或投掷。

![收拢与展开状态](preview.png)

收拢长约 230 mm，全部拉直约 285 mm；每节长 29 mm、宽 20 mm，壳体厚 10.0 mm（含凸出销头总厚 11.2 mm），单关节行程 11 mm、弯曲范围 ±35°。星形头跨度约 56 mm、厚 5 mm，转动范围 ±40°。

## 打印

拓竹 P2S、PLA、0.4 mm 喷嘴；100% 比例，首层及其余层均 0.20 mm，4 圈墙、20% 填充，小区域填充阈值 100 mm²（保证弹舌内部填充路径），免支撑。

底座开口朝上，盖板外表面贴床，**连接片凹槽面朝下贴床**，星形头平放，锁销头部贴床。保持文件朝向，关闭自动定向；全套 STL 导入为一个对象下的多个零件，不合并相邻实体。取件后清理孔内毛边，确认盖板弹性舌切缝贯通。

## 装配与使用

1. 将五个普通底座和一个末节底座开口朝上排好，滑槽口朝向上一节，带叉座的末节放在最后。
2. 将连接片实心宽头从上方放入前一节尾部的独立收口槽，抬高的连接颈穿过尾部上方开口；圆头放入下一节滑槽，**凹窝朝上、抬高的连接颈朝向下一节**。第一节前端滑槽留空。
3. 星形头放入末节叉座并对齐孔，根部限位舌指向链条，位于两根限位柱之间，不翻面安装。
4. 覆盖对应盖板，每节装两根锁销，星形头转轴装一根。销头贴平，直柱末端距底面 0.2 mm，不突出底面。

展开时逐节直拉，完全释放定位键后再弯曲；收拢时先对齐，再逐节推近至卡位入槽。拆卸时从底部顶出直柱销末端并托住盖板，不拉扯连接片。零件出现白化或裂纹时更换。收拢状态不作为承力杆。

底座、盖板、连接片和锁销使用同次生成的配套文件；不要整体缩放 STL 来调整配合。
