# 星链伸缩杖 · FDM

六节链条收拢成杆，逐节直拉展开后，可在一个平面内弯曲；卡位用于保持收拢形态，圆钝四角星形头可独立转动。用于手持变形和展示，不用于甩动或投掷。

![收拢与展开状态](preview.png)

收拢长约 230 mm，全部拉直约 285 mm；每节长 29 mm、宽 20 mm，壳体厚 10.0 mm（含凸出销头总厚 11.2 mm），单关节行程 11 mm、弯曲范围 ±35°。星形头跨度约 56 mm、厚 5 mm，转动范围 ±40°。

## 打印

拓竹 P2S、PLA、0.4 mm 喷嘴；100% 比例，首层及其余层均 0.20 mm，4 圈墙、20% 填充，小区域填充阈值 100 mm²（保证弹舌内部填充路径），免支撑。

底座开口朝上，盖板外表面贴床，**连接片凹槽面朝下贴床**，星形头平放，锁销头部贴床。文件已设置打印朝向，不再自动定向；全套 STL 导入为一个对象下的多个零件，不合并相邻实体。取件后清理孔内毛边，确认盖板弹性舌切缝贯通，直柱销无分叉槽。

## 装配与使用

1. 将五个普通底座和一个末节底座开口朝上排好，滑槽口朝向上一节，带叉座的末节放在最后。
2. 将连接片实心宽头从上方放入前一节尾部的独立收口槽，抬高的连接颈穿过尾部上方开口；圆头放入下一节滑槽，**凹窝朝上、抬高的连接颈朝向下一节**。第一节前端滑槽留空。
3. 星形头放入末节叉座并对齐孔，根部限位舌指向链条，位于两根限位柱之间，不翻面安装。
4. 覆盖对应盖板，每节装两根锁销，星形头转轴装一根。销头贴平，直柱末端距底面 0.2 mm，不突出底面。

展开时逐节直拉，完全释放定位键后再弯曲；收拢时先对齐，再逐节推近至卡位入槽。拆卸时从底部顶出直柱销末端并托住盖板，不拉扯连接片。零件出现白化或裂纹时更换。

## 核心参数

参数来源：`parameters.json`。

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `link_length_mm` | 29.0 mm | 链节本体长度，为固定端宽头与挡墙提供承靠空间。 |
| `clearance_per_side_mm` | 0.30 mm / 侧 | 滑动间隙；增大更易滑动，也会增加晃动，调整后仍须保证固定端挡墙厚度。 |
| `detent_interference_mm` / `detent_depth_mm` | 0.70 / 1.10 mm | 卡位干涉控制解锁时的弹舌挠动，凹槽深度容纳凸起；干涉须比槽深小至少 0.15 mm。 |
| `detent_root_diameter_mm` | 3.6 mm | 圆顶定位凸点的根部直径；与连接片凹窝配合保持收拢。 |
| `anchor_wall_minimum_mm` / `anchor_neck_fillet_mm` | 2.40 / 0.80 mm | 固定端实心宽头的挡墙最低厚度及连接颈根部圆角半径，影响防脱与根部强度。 |
| `locator_clearance_mm` / `locator_vertical_clearance_mm` | 0.15 / 0.20 mm | 双侧粗榫的单侧横向及上下间隙，承担抗晃约束；卡位负责保持收拢。 |
| `locator_engagement_mm` / `locator_width_mm` | 3.8 / 3.2 mm | 粗榫插接深度与宽度，保留入口倒角及免支撑斜面，尖端最薄 2.4 mm。 |
| `base_height_mm` / `body_height_mm` / `slider_thickness_mm` | 7.6 / 10.0 / 3.4 mm | 底座高、壳体厚及连接片厚度参数（抬高连接颈厚度）；盖板主体厚 2.4 mm。 |
| `floor_mm` | 1.6 mm | 底板厚度；需保证连接片下方间隙及粗榫尖端至少 2.4 mm 厚度。 |
| `flag_thickness_mm` / 有效长度 | 1.6 / 10.4 mm | 弹舌厚度及根部至凸点的有效长度，影响解锁挠动。 |
| `pin_shaft_length_mm` | 9.8 mm | 柱径 2.96 mm，销头厚 1.2 mm，销总长 11.0 mm；13 根统一使用。 |
| `stroke_mm` / `joint_angle_deg` / `star_angle_deg` | 11 mm / ±35° / ±40° | 单关节伸缩行程、链节弯曲范围与星形头转动范围。 |

修改设计参数后须从源码重建，底座、盖板、连接片和锁销须使用同次生成的配套文件；不要整体缩放 STL 来调整配合。

## 验证状态

通用几何、装配与运动检查通过，包含固定端防脱、卡位运动包络和锁销插入路径。

按上述打印配置完成切片，归档几何与 STL 一致，卡位与固定端防脱等关键路径检查通过，打印盘无警告。

**六节整机、保持力和寿命待实物验证**。先试打一组相邻链节，检查：

- 正常拿动不自行伸长，刻意直拉能展开；凹窝卡位进出顺畅，收拢插接不卡滞，左右晃动可接受，固定端宽头不窜出收口槽。
- 检查销与盖板是否松脱，确认销末端不突出底面。
- 连续操作 100 次后复查松动、白化、裂纹及销退出情况。

展开直拉应不脱出，收拢状态不作为承力杆。
