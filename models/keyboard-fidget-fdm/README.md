# 键盘解压按键器 · FDM

五件打印单键解压器：外壳、底座、导向柱、24 mm 方形键帽和可更换一体弹性盒。主体 45 × 45 mm；键帽行程 3 mm。另备两颗适用于塑料的 ST2.2 × 8 mm、90° 沉头自攻螺钉，头径不超过 4.4 mm，使用螺丝刀装拆。

## 打印

外壳与弹性盒使用 PLA Tough+，底座、导向柱及键帽可使用普通 PLA；采用各自对应材料预设。使用 P2S、0.4 mm 喷嘴、0.20 mm 层高、首层线宽 0.50 mm、3 圈墙、实体填充（底部实心层设为 100 层，覆盖零件全高）、Arachne，关闭支撑。保持 STL 的导出方向：底座、弹性盒与导向柱平底落床；外壳和键帽顶面落床。

## 装配与使用

[打开交互式装配动画](../../index.html?model=keyboard-fidget-fdm&mode=assembly)。动画展示安装顺序，不模拟弹性受力。

1. 底座平放，捏住弹性盒外框，将不同宽度的两个定位缺口对准底座定位块后垂直落座。
2. 放入导向柱，平底承压板接触两只回弹接触垫；宽凸轮朝向两侧段落臂触头。导向柱可反向装入，但反向不能正常工作。
3. 从上方垂直罩合外壳，保持凸轮朝向段落臂触头。垂直压下，使两侧定位柱的双斜面凸头越过窄槽，进入上端落位空间，直至外壳固定座抵住底座硬落座面。外壳顶板捕获导向柱止肩，并承接按到底后的额外载荷。
4. 扶住外壳，从底面交替轻拧两颗指定自攻螺钉至刚好贴合，螺钉头低于底面 0.2 mm。固定座直接抵住底座，不夹压弹性盒；不要强行拧紧。
5. 键帽宽方插口压至导向柱止肩。检查中心与四角均能回弹，慢按确认凸轮释放和复位路径。

拆卸时先取下键帽，用螺丝刀退出底面两颗螺钉，再垂直拉开外壳，更换整块弹性盒。

外壳、底座、导向柱和弹性盒须使用同套文件中的配套零件。

## 检查结果

五件实体、装入路径、螺钉接口及装配动画网格一致性检查通过。运动与切片材料包络检查覆盖中心、四角偏压及完整按下与回程，按到底后解除凸轮顶压；回弹臂通过 PLA Tough+ 名义应变线性筛查，切片无需支撑。

运动检查采用无摩擦的线性梁变形近似，不包含扣合槽壁弹性；定位凸头越过窄槽的弹性压入与拉开尚未得到验证。
