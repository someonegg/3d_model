# 伸缩手里剑玩具 · FDM

手动旋转中央转盘，四个宽圆端滑翼同步伸缩。全 PLA 七件装配，无五金；用于手持把玩。预览中的颜色仅区分零件，单色打印即可。

## 打印

- 机型：拓竹 P2S，0.4 mm 喷嘴，PLA；100% 比例，单位 mm。
- 首层和其余层高均为 **0.20 mm**，3 圈墙、15% 填充、Arachne 墙生成器，关闭支撑。外墙 45 mm/s、内墙 80 mm/s 作为起点。
- 保持文件朝向：底座平底朝下，滑翼销柱朝上，转盘旋钮朝上，上盖外侧大平面朝下、四个钩朝上。不要自动定向，不合并相邻零件。
- 切片中检查上盖四根 1.6 mm 宽弹舌、四个滑翼销柱、转盘曲线槽边缘，以及止挡槽上方约 3.5 mm 的局部桥接。配合面已有首层避让，不要再通过扩大孔洞来修改全部接口。
- 上盖倒置打印时，钩头保持面向外悬伸约 0.85 mm；切片时检查该处挤出路径，首件观察悬挑成形。

## 装配与使用

[打开交互式装配动画](../../index.html?model=retractable-shuriken-fdm&mode=assembly)。网页入口需要站点环境；也可下载 [assembly.glb](assembly.glb) 或查看 [爆炸图](exploded.png)。动画演示位置与运动，不模拟卡扣弹性。

1. 底座平放，开口朝上。四个滑翼的销朝上，分别放入四条导轨，圆端朝外，全部推至内侧。
2. 对准中央轴及旁边的止挡销，放下转盘；让四个滑翼销分别进入四条曲线槽。槽端对不上时微调翼片位置，不要强压销柱。
3. 旋钮穿过上盖中央孔，四个卡扣对准底座侧窗，逐个轻压到位。确认上盖平齐且四个钩都已进入侧窗。
4. 握住外壳中部，慢慢旋转中央旋钮，检查四翼同步伸缩。到止挡即停止，不继续强扭。结构没有自动回弹或端点锁扣，保持力取决于实际打印配合。

拆卸时从上盖四个外缘开槽，将弹舌自由端轻压向中心，同时逐处抬起上盖；也可从侧窗用薄塑料片把钩向内推。不要直接硬撬上盖。打开时保持底座朝上，避免零件散落。

## 核心参数

参数来源：`parameters.json`。

| 参数 | 当前值 | 作用 |
| --- | --- | --- |
| `travel` / `rotation_degrees` | 15 mm / 60° | 每翼行程及对应转盘转角，决定伸缩幅度。 |
| `guide_clearance` | 0.25 mm / 侧 | 导向滑动间隙；增大更易滑动，也会增加晃动。 |
| `axial_clearance` | 总计 0.30 mm | 活动件上下方向的余量，避免被盖板夹紧。 |
| `clip_length` | 14 mm | 卡扣弹舌切缝长度，影响柔顺度与装拆配合。 |
| `clip_width` | 1.6 mm | 弹舌宽度，影响卡扣强度与柔顺度。 |
| `clip_deflection` | 0.7 mm | 钩头径向扣入量，影响保持力与拆卸力度；尚待实物验证。 |

修改设计参数后须从源码重建，使用同步生成的配套零件；不要整体缩放 STL 来调整配合。

## 验证状态

通用几何、伸缩运动与装配路径检查通过；P2S 切片结果未复核。

**当前为待实物验证的原型**。数字检查不能确定手感、摩擦、保持力或寿命。首件完成 100 次往返和 10 次拆装，观察卡滞、脱轨、销柱松动，以及卡扣白化、开裂或永久变形；出现问题时停用并修正后重打。
