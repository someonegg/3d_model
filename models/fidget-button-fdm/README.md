# 解压按键 · FDM

仅用 PLA 打印的手持单键。直径 42 mm，装好后约 21 mm 高；按帽露出外壳约 1.5 mm，设计按压行程 1.5 mm。两个对向悬臂弹片提供轻柔、安静的回弹，中央止挡限制最大行程。弹片可单独更换。

## 下载与尺寸

- [整套四件](fidget-button-fdm.stl)：已排版的外壳、按帽、底盖及弹片。
- [备用弹片](fidget-button-fdm-spring.stl)：独立更换件。

## 打印

- STL 单位为 mm，以 100% 比例导入 Bambu Studio。一个 STL 排好外壳、按帽、底盖和弹片四个分离零件；不要选择“组装”为单一实体，也不要自动改变朝向。
- 选择拓竹 P2S、0.4 mm 喷嘴、PLA 材料配置。建议首层 0.20 mm，后续 0.16 mm；3 圈墙，15% 填充，开启冷却。弹片厚 1.0 mm、宽 2.0 mm，检查切片预览中两根弹臂连续成形。
- 四件均已以平面贴热床排版。外壳的可见顶面朝下打印；按帽的按压面朝下打印。设计目标为免支撑；重点查看按帽外缘约 1.2 mm 的外挑，若切片显示不可接受的悬空路径，应先降低外墙速度或局部加支撑，不要直接打印失败路径。
- 打印后去除底盖的毛边和接缝凸点。避免在弹片上加热整形或强行掰弯。

## 装配与调节

1. 将外壳翻至顶面朝上，从底部把按帽穿过中央孔，按压面向外。按帽的外缘应被顶板挡住，能自由上下移动。
2. 将弹片平放在底盖环形支柱顶部。两根弹臂的自由端朝中心，底盖中央止挡位于两臂之间。
3. 保持零件同轴，把底盖从外壳底部轻压入。底盖外圆的六处浅凸筋形成压配。按帽底部的环形推杆应接触两根弹臂，按压时回弹，不应刮蹭外壳。
4. 若底盖过紧，少量修整六处凸筋；若过松，可在 `src/build.py` 的 `grip` 函数中略增 `0.40` mm 凸筋高度并重建。若按帽卡滞，检查孔内接缝与毛边，再考虑增大按帽间隙；不要整体缩放 STL，否则配合关系会同时改变。

底盖可从外缘轻撬拆下，弹片磨损后可下载“备用弹片”变体单独打印。首次打印后建议连续按压数十次，检查回弹和底盖保持力；若弹片出现白化、裂纹或永久变形，应停用并更换。

## 维护与重建

`src/build.py` 生成整套打印排版、独立备用弹片及预览图；`src/verify.py` 检查导出 STL 的闭合零件、尺寸和标称行程。执行 `npm run models:build -- fidget-button-fdm` 可重建和校验。
