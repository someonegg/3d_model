# 解压按键 · FDM

全 PLA 四件手持按键，直径 42 mm，装配高度约 21 mm，按压行程 1.5 mm；弹片可单独更换。

## 下载

- [整套四件](fidget-button-fdm.stl)：外壳、按帽、底盖、弹片，已按打印方向排版。
- [备用弹片](fidget-button-fdm-spring.stl)：独立更换件。

## 打印

- P2S、0.4 mm 喷嘴、PLA；单位 mm，100% 比例，保持排版与朝向，不合并为单一实体。
- 首层 0.20 mm，其余 0.16 mm；3 圈墙、15% 填充，开启冷却。
- 外壳顶面与按帽按压面朝下，四件均平面贴床。设计为免支撑；打印前检查按帽外缘约 1.2 mm 悬挑，必要时局部加支撑。
- 弹片厚 1.16 mm、弹臂宽 2.0 mm，检查两根弹臂连续成形。冷却后取件，清理接缝和毛边，不加热或强掰弹片。

## 装配

1. 外壳顶面朝上，从底部把按帽穿过中央孔，按压面向外，确认能自由上下移动。
2. 弹片平放在底盖环形支柱上，自由端朝中心，中央止挡位于两臂之间。
3. 保持同轴，将底盖从外壳底部轻压入。按帽环形推杆应接触两根弹臂，按压能回弹且不刮壳。

底盖过紧可少量修整六处凸筋；按帽卡滞先清理孔内毛边与接缝。不要整体缩放模型。拆卸时用薄塑料撬片从两个对向撬口交替轻撬，避免单侧硬扳。

首次连续按压数十次，检查回弹与底盖保持力；弹片出现白化、裂纹或永久变形时停用并更换。
