# 解压按键 · FDM

四件手持按键，直径 42 mm，装配高度 23.4 mm，静止时按帽高出外壳 4 mm，中心按压行程 3 mm，到底仍高出 1 mm；弹片外圈带双平面导向座，弹片可单独更换。预览图展示组装后的静止状态。

## 打印

- P2S、0.4 mm 喷嘴；弹片用 PLA Tough+，刚性件可用普通 PLA，采用对应材料预设；单位 mm，100% 比例，保持排版与朝向，不合并为单一实体。
- 首层 0.20 mm，其余 0.16 mm；3 圈墙、实体填充，开启冷却。
- 外壳顶面与按帽按压面朝下，四件均平面贴床。设计为免支撑；打印前检查按帽外缘约 1.2 mm 悬挑，必要时局部加支撑。
- 弹臂名义厚 0.70 mm、宽 2.4 mm（切片共四层，层顶为 0.68 mm），外围导向座总高 4.9 mm，检查两根弹臂连续成形。冷却后取件，清理接缝和毛边，不加热或强掰弹片。

## 装配与使用

1. 底盖平底朝下放在桌上，环形支柱和中央止挡朝上。
2. 弹片的两根弹臂贴近底盖、外围导向座朝上，将弹片外圈平放在底盖环形支柱顶面。外圈承担支承，弹臂悬空；不要先把弹片投入外壳。
3. 按帽按压面朝上，两处接触垫朝下。对准按帽裙边与弹片导向座的两侧平面，轻放入导向座。允许相差 180°，不能旋转 90°强塞；接触垫会对准两根弹臂端部。
4. 从上方套下外壳，让按帽按压面穿过中央孔。将外壳接缝单刻线对准底盖的双刻线装入标记，轻压合拢；固定底盖，将外壳转约 30°至底盖的单刻线锁紧标记。六处宽缓凸台逐渐压紧。
5. 试按中心与四角，确认顺畅回弹。静止时两处接触垫接触弹臂；到底时按帽中央小环接触底盖中央柱，由刚性止挡承担额外按压力。

外围导向座负责按帽的横向导向与防转，不参与弹臂弯曲。使用同套文件中的配套零件。

旋转过紧可少量修整六处宽缓凸台；按帽卡滞先清理孔内毛边与接缝。不要整体缩放模型。拆卸时固定底盖，反转外壳约 30°回到双刻线装入位置，再分离壳盖；必要时用薄塑料撬片从两个对向撬口交替轻撬。

弹片出现白化、裂纹或永久变形时停用并更换。

## 检查结果

通用几何、零件专项校验、完整行程偏压及装入与旋转路径检查通过。PLA Tough+ 弹臂名义应变通过线性筛查；该筛查不包含根部应力集中、摩擦、蠕变与疲劳。

切片关键路径检查通过，包含首层弹臂与根部；未生成支撑，打印盘无警告。
