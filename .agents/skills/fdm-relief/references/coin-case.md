# 人物硬币：局部重塑案例

本例源自萨卡加维亚硬币的 FDM 适配与眼鼻调整，提供数字模型验收中遇到的失败模式。具体尺寸、工艺参数和验收阈值应从当前模型确定，不沿用案例的历史数值。

## 遇到的问题与修正思路

- **眼形变成眼圈或眼袋**：早期方案通过宽厚上下眼睑和凹瞳增强眼形，后续对照发现它们容易形成完整凸圈。可用上眼睑表达眼形，保留低矮眼球与浅眼口，将下眼睑融入脸颊；独立瞳孔按尺度及视线表达需要选择，不能作为默认要求。
- **远侧眼成为独立鼓包**：透视缩短之外还需控制体积。检查是否有额外垫高眼部的底座，让远侧眼融入鼻根与脸部转折，而非只把近侧眼等比例缩小。
- **替换边界出现浅环**：即使使用平滑接缝，旧眼窝与新基础体积不匹配仍会产生环状残影。本轮通过调整支持范围、保留相容的宽缓眼窝基础消除浅环；不能仅凭权重函数平滑就判定接缝合格。
- **鼻尖像孤立圆包**：优先连接鼻根、鼻梁与鼻尖的坡面，减小鼻尖相对鼻梁高差，并让鼻翼融入面颊。降低峰值后仍需检查峰顶形状；不要求鼻尖成为整个正面的最高点。
- **鼻尖被压平或变矮**：检查整个人物的软限高、归一化及接缝平滑。独立安排鼻梁、鼻尖和鼻翼高度，先测量再作局部补偿，不拉伸整个主体或照搬补偿量。
- **鼻底像第二条嘴缝**：横贯鼻底的槽过长，且局部混合留下旧槽残影。缩短凹槽、检查旧曲面残留，并收紧下方过渡，避免影响原嘴部。
- **鼻部覆盖眼睛或眼睑改变脸缘**：检查局部支持范围、混合权重与合成顺序。靠近脸缘时限制修改范围，并复查滤波、插值后的眼部与原轮廓。

## 可复用的验收方法

1. 保留凹瞳时检查截面开口、围合及内接直径；取消凹瞳时改查上眼睑与眼口的分离，以及眼球向脸颊过渡是否出现独立凸峰。
2. 测量鼻尖与鼻梁、两侧鼻翼的相对高度，沿鼻梁至鼻尖取样检查坡面连续性，并检查顶部小高度区间的面积，排查尖峰或宽平顶。
3. 需要逐点保持曲面时，可保存修改前 Float32 顶点或完整 STL，以一致拓扑比较非修改区，并固定未改一面的哈希。插值采用与 STL 相同的三角形划分；支持区余量按实际滤波和采样确定。
