# 牡丹鹦鹉书签 · FDM

依据用户照片 IMG_3228.HEIC 中前景牡丹鹦鹉转绘：保留朝左侧首、圆眼、浅色弯喙、蓬松胸羽及收拢翅膀。移除笼条和后方鸟影，将塑料站杆改为树枝；遮挡的足爪及尾部为艺术补全，不是精确扫描。使用内置 imagegen 生成底图，提示词见 source-prompt.md。source.png 是唯一重建素材；原始私人照片不复制到公开模型资源。

背景采用浅灰远树林、下方阔叶与蕨叶；上方大幅垂叶已去除，延续淡树林。整图等比例满幅裁切，鸟头附近保留亮部。背景修订保留主体和下方植物的视觉形态与布局，不保证主体网格逐点不变；仍以单一 source.png 重建，不依赖旧版本素材。

## 打印

- 成品 45 × 150 mm，圆角 3 mm，平背单面，无绳孔；总厚 0.52～1.32 mm。
- 沿用珠海渔女书签的黑白 PLA 耗材叠层工艺，按 P2S、0.4 mm 喷嘴设计。
- 平背朝下，100% 比例与填充；首层 0.20 mm，其余 0.08 mm，关闭可变层高、支撑和熨烫。
- 共 15 层；前 5 层黑色至 0.52 mm，第 6 层开始换白色（该层顶面 0.60 mm），共 0～10 层白色覆盖。STL 不携带换色信息。
- 高度表达白料覆盖厚度，不表示鸟的解剖凸凹。11 档灰度未做耗材透光校准，preview.png 是示意，实物灰度取决于耗材。

## 验收与重建

专项验收读取最终 STL 检查尺寸、单体、平背、离散层高、源图方向，并输出双光照表面及相邻层占据预览。关键眼部截面在最终网格采样上测量；细小羽丝和眼部高光不承诺逐根打印。通用流程检查闭合性、绕序、退化面与正体积。未做完整自交检测、切片器挤出路径检查或实际试打印。
