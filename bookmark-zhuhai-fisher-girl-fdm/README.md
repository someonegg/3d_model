# 珠海渔女书签 · FDM

珠海渔女举珠立于海湾礁石，搭配淡远山与海浪。黑底与不同厚度的白色覆盖层表现水墨灰度，沿用江南石桥书签的工艺。雕塑原作为潘鹤《珠海渔女》；底图为 AI 生成的艺术化表现，非雕像精确扫描。

`source.png` 是唯一建模底图，整张图统一裁切、滤波并转换为灰度层级，不混合其他背景。

## 文件与打印

- `bookmark-zhuhai-fisher-girl-fdm.stl`：45 × 150 mm，厚 0.52～1.32 mm，圆角半径 3 mm，平背单面，无穿绳孔。
- P2S、0.4 mm 喷嘴、黑白 PLA，100% 比例，平背朝下。
- 首层 **0.2 mm**，后续层高 **0.08 mm**，填充 **100%**；关闭可变层高、支撑和熨烫，不缩放 Z。
- 共 **15 层**，前 5 层黑色至 0.52 mm；**第 6 层开始换白色**，该层顶面为 0.60 mm。白料覆盖 0～10 层，最高 1.32 mm。
- AMS 将第 6 层起映射为白料；无 AMS 在第 6 层开始前暂停并换白、排净黑料。温度与打印板按实际耗材配置。STL 不携带换色或暂停信息。

## 灰度与校验

`parameters.json` 使用 11 档线性灰度，未校准耗材透光性。`preview.png` 是正式灰度示意，不是实物打印照片；灰度高度表示白料厚度，不表示人物解剖深度。

专项校验直接读取最终 STL，检查成品尺寸、平背、单一连通体、0.08 mm 离散高度、圆角、源图方向，以及头部与双臂之间两处亮部间隙不低于 0.4 mm。通用校验检查闭合性、绕序、退化面与正体积；未执行完整自交检测，也未进行实际试打印。

## 重建

```sh
npm run models:build -- bookmark-zhuhai-fisher-girl-fdm
npm run build
```

生成脚本支持 `MODEL_OUTPUT_DIR`，共享书签几何与灰度映射位于 `tools/bookmark_relief.py`。重建生成 `bookmark-zhuhai-fisher-girl-fdm.stl` 和正式 `preview.png`，随后执行通用及必要的专项校验；失败时保留上次成功产物。打印前在切片器核对首层、15 层总数及第 6 层换色。
